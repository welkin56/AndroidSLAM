- [2026-09-27 阶段五 M2：把 C++ 的 stdout/stderr 接进 logcat](2026-09-27-m2-stdout-to-logcat.md)
  —— 阶段五 M2。**排在碰 ORB-SLAM3 之前的最后一步**：它所有的进度和错误都走
  `cout`/`cerr`（Android 上默认进 `/dev/null`），而且用 `exit(-1)` 报错不走 Java
  异常路径 —— **表现是「App 整个消失、logcat 干干净净」，`ndk-stack` 对它无效**。
  做法：`pipe()` + `dup2` 顶掉 fd 1/2 + 一个 pthread 按行喂 `__android_log_write`
  （tag `slam`）。**不用 Java 的 `Log`**：这个线程不是 JVM 建的，没有 `JNIEnv`
  也没有 ClassLoader。**四个容易漏的细节**：行缓冲（否则日志是「卡住然后一大坨」）、
  按行重组（`read` 只给字节流）、**超长行分 3000 字节块**（logcat 单条上限约 4 KB，
  超了静默截断）、**攒半行超时 200 ms 吐出**（否则不带 `endl` 的那句永远看不见）。
  **第五个是用户问出来的**：光有超时兜不住 —— `poll` 一有数据就返回，写方只要不停顿，
  超时分支永远轮不到，攒行缓冲就一路涨。修法是**让缓冲上限等于分块大小**，
  硬切点于是和分块点重合，结果不变而内存卡在 4 KB。
  **一根管道不拆两根**：拆开能按级别过滤，但两个读线程一跑就**丢了 `cout`/`cerr`
  的先后顺序**，而时序比级别要紧。
  **拆文件（用户提出）：`cpp/` 下平铺成 `jni_bridge.cpp`（符号层）+
  `log_redirect.{h,cpp}`（基础设施）**，但**不拆 `include/`+`src/`** —— 那套结构是给
  库的使用者准备的，而我们的 `.so` **没有 C++ 使用者**（唯一消费者是 Kotlin，走 JNI）。
  拆出去的东西必须变外部符号，套一层 `namespace slamlog` 收口：导出的是
  `_ZN7slamlog7installEv` 一个名字，不是 `emit`/`logThread` 这种容易和

- [2026-09-26 修好编辑器智能感知：把编译数据库导出到固定路径](2026-09-26-intellisense-compile-commands.md)
  —— 用户报告智能感知读不到报错。**文件其实是生成好的**，问题是两个事实叠在一起：
  ① 用的是官方 `ms-vscode.cpptools`（不是 clangd），它**不会自动去 `.cxx` 里找**，
  而工作区里**一份 `c_cpp_properties.json` 都没有**；② **`compileCommands`
  不支持通配符**，而 AGP 把它放在 `app/.cxx/<类型>/<哈希>/<abi>/` 下——
  **哈希会变**，配死路径就会某天突然失效，且症状极难定位。
  解法：CMake 加 `add_custom_target` 每次构建后把它拷到**固定路径**（`CMakeLists` 旁边）。
  **用 custom_target 而不是 `configure_file`** —— 编译数据库在 configure 末尾才写出。
  **⚠️ 第一版（只写 `ALL`）实测没用**：`build.ninja` 里明明挂着它，
  但 `.ninja_log` 显示只跑了 `jni_bridge.cpp.o` 和 `libslam_jni.so` ——
  **AGP 只构建它要的那个 `.so`，不走 `all`**。已改成 `add_dependencies`（**这一版生效了**）。
  **第二层问题**：文件出来了但智能感知仍报「无法打开 jni.h」——
  **cpptools 解析编译命令时不认 `--sysroot`**，它单独跑编译器问系统头时没带，
  拿到的是宿主目录。修法：`c_cpp_properties.json` 里补 `compilerArgs` 两行
  （参数本来就在编译命令里，只是要再告诉它一次）。
  顺带查清「ORB-SLAM3 那边为什么 CMake 之后自动就灵」：全局设了
  `C_Cpp.default.configurationProvider = ms-vscode.cmake-tools`，**差别在宿主 vs 交叉**。
  走过但**否决**的路：CMakePresets + 多根工作区（代价是丢掉"整个 SLAMAPP 一眼看全"）。
