# 2026-10-25 地图重命名：名字就是目录名

一句话：第一次保存地图时问一次名字；之后在入口页长按卡片「重命名」。
名字落在**会话目录名**上，目录里唯一的 `.osa` 跟着同名，列表只显示一个名字。

## 动机

地图原来只有时间戳：目录 `maps/20261025-091233/`，`.osa` 是保存那一刻的另一个时间戳。
首页列表显示成「20261025-091233 / 20261025-091405」，隔几天就分不清哪张是哪张。

## 改动

**名字往哪放**

- `TrajectoryStore.cleanMapName()`：名字 → 可用目录名 —— `/`、`\`、控制字符换成 `_`，
  去首尾空白，限长 40；`.` / `..` 视为空。
- `TrajectoryStore.uniqueMapDir()`：`maps/` 下取没被占用的目录，撞名加 `-2`、`-3`。
- 归属规则集中在 `TrajectoryStore`，入口页和主界面都用它，不各写一份。

**第一次保存时命名（MainActivity）**

- `askMapSave()`：目录里还没有 `.osa` 时，点「保存」后再弹一次名字输入（`askMapName`），
  预填目录名（时间戳）。「覆盖」不问；「另存为」按第一次处理，也问。
- 改名发生在 `startMapSave()` **之前** —— `pendingArchive` 存的是 `sessionDir`，
  存完再改就对不上。改名后 `sessionDir` 指向新目录，`.osa` 也按新目录名保存。
- `renameSessionDir()` 成功后调 `rebaseSessionPaths()`：`curTrajBase` / `curRecDir` /
  `lastRunDir` 里指向旧目录的路径全部换到新目录下。不做这一步，存完归档本趟轨迹时
  源文件路径已经失效（`moveInto` 找不到文件，静默跳过）。
- 命名弹窗取消 = 这次保存作废，走原来的「不保存」分支（恢复 atlas）。留空 = 用时间戳。
- 弹窗串联：`askMapSave` 的「保存/另存为」先把 `naming = true`，
  地图弹窗的 `onDismiss` 就不再急着问轨迹问题，等命名弹窗结束再问。
- `newSessionDir(name)`：给了名字就用名字建目录，「另存为」走这条。

**入口页重命名（EntryActivity）**

- 长按卡片从「直接弹删除」改成小菜单：`重命名` / `删除`（和历史轨迹那套一致）。
- `askRenameMap()` → `textInputDialog`（预填当前目录名）→ `renameMap()`：
  改目录名；目录里**只有一份** `.osa` 时把它也改成同名，多份时只改目录。
- 改名后 `refreshMapList()`，排序按 `.osa` 的 mtime，不变。
- 分区标题右侧提示改成「长按重命名 / 删除」。

**弹窗复用**

- 新增 `InputDialog.kt`：`Activity.textInputDialog(title, initial, onCancel, onOk)`，
  从 `MainActivity` 的私有实现挪出来，入口页也要用。
- 补上 `onCancel`：没点「确定」就关掉（返回键 / 点外面 / 取消）时回调，
  调用方不会卡在「等命名结果」上。

## 决策

**① 名字 = 目录名，不另存一份元信息。**
一个目录 = 一张地图 = 列表一行，磁盘上只有一个真相：`adb pull` 出来、备份、换机器，
名字都跟着走。写进 `session.json` 之类的「展示名」会让文件管理器 / adb 里永远只有时间戳，
而且要维护两个真相的一致性。

**② 目录里唯一的 `.osa` 跟着同名。**
列表标题本来就有「文件名 ≠ 目录名时显示 `目录 / 文件`」的规则；同名之后只剩一个名字。
多份 `.osa` 时只改目录 —— 文件名是它们之间唯一的区分，不能抹掉。

**③ 只在第一次保存时问名字，之后不再问。**
已有 `.osa` 的保存是「覆盖」，路径不该变；名字要改就去首页长按改，两处入口不重复。

**④ 取消命名 = 不保存这一趟。**
命名是保存动作的一部分，取消它等于取消保存，与「不保存」走同一条恢复 atlas 的路径。
留空则用时间戳，避免用户清空输入框后没法继续。

**⑤ 改名失败不中断保存。**
目录改名失败（目标被占、权限）时打日志 + 横幅提示「已按原名保存」，地图照样存下来 ——
丢名字比丢数据严重得多。

**否决：**
- **只记展示名（元信息文件）。** 见 ①。
- **只改 `.osa` 文件名、目录保持时间戳。** 列表会变成「时间戳 / 名字」，时间戳仍然抢眼。
- **把名字写进 `.osa` 内部。** 那是 ORB-SLAM3 的序列化格式，为一个显示名改格式不值。
- **单独记住「上次打开的地图」，改名时同步。** 主界面没有跨进程的路径状态，
  入口页可见时主界面必然已经 finish，不需要。

## 遗留

- **改名会丢「已隐藏」标记**：`PREF_HIST_HIDDEN` 存的是轨迹文件的绝对路径，
  目录改名后这些路径全部失效，隐藏过的轨迹会重新显示，旧字符串也留在偏好里。
  影响仅限显示。
- **记录里的来源图名不跟着改**：`session.json` / `traj-*.json` 的 `map_source`
  是保存时的来源文件名（备注性质）。
- **轨迹文件名不变**：`traj-<stamp>.txt` 仍是时间戳，与地图名无关。
- **入口页改名是主线程 `renameTo`**：同一分区内是改目录项，很快；跨分区不可能（都在 `maps/` 下）。
- **没有「撤销重命名」**。
- **主界面「另存为」后 `curRecDir` 仍指向旧会话目录**（原有行为，未改）：若之后删除本趟录像，
  删的是源目录里那份。与本次改动无关，记一笔。
