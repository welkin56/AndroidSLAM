# 2026-09-23 SLAM 尺度验证通过：三对读数，误差预算闭合

## 动机

fx 与 IMU 噪声参数定案后，做阶段四遗留的「验尺度」：用户拿长 1.6m 的物体，
要求验证 SLAM 轨迹的米制尺度。这次同时是「新激励协议 + 新 NoiseGyro（修正 19 倍）」
的首场实战。过程里结论两次反转（两对时过早乐观 → 第三对推翻 → 误差预算里落回
实处），值得完整记下。

## 改动

**无源码改动。** 测试资产：

- `session_1790161277904` —— 57.7s、1721 帧 / 23221 条 IMU、零丢帧、IMU 领先
  311ms。**新协议首战：161 关键帧、1661/1721 位姿（96.5%）、8 次重置全部恢复、
  VIBA2 通过**——对照激励不足时代的 47/133 KF 与重置循环，轨迹质量显著变好。

  click_points 默认覆写同一 json，第二对起必须 `--out` 分开存（踩过一次差点覆盖）。

## 决策

- **否决（我方过早结论）：「新协议把尺度误差缩到 1/3」。** 两对时看到 -2.57% /
  -4.68% 就和老数据 ±7% 对比下了结论；第三对 **+2.36%** 直接推翻——三对散布
  ±3.7pp 与老数据的散布同量级。**2 个样本不下结论**，又一次验证了 A/B 的教训。
- **否决：把散布归因「点击糙」。** 对 3 的重投影 0.02~0.6px 是三对里最干净的，
  却和对 2 差 7pp——散布主因是**远端标记视差仅 ~11° 的弱深度约束**（近端 34°）：
  杆子顺景深摆放时，深度方向的微小扰动被放大成厘米级。这是三角化几何的物理，
  不是 SLAM 算法的锅。
- **采用：误差预算分解并核对闭合**（用户提出的三分解，量级全部对上）：
  点击 1~2px @拍摄距离 3m ≈ 2~4cm ＋ 真值 1~2cm ＝ 3~6cm ≈ 实测散布 5~6cm
  （±3.7pp × 1.6m）。**预算闭合，SLAM 尺度误差栏无残余。**
- **采纳用户的精度判断**：手机 VIO 的尺度精度 1~3% 是正常偏好水平，几厘米误差
  对「拿手机量东西」的用途完全可接受；此前「统计上分不开 0」的说法过于苛刻——
  分不开 0 恰恰说明没有系统性偏差，是**好消息**。

## 验证

三对读数（`--truth 1.600`，fx=435.2，基线 1.47~1.48m，帧对均精确命中关键帧）：

```
帧对          距离(m)   尺度偏差   重投影(px)      视差(近/远)
1260&1351     1.5588    -2.57%    0.4~1.4         34.4° / 11.1°
1260&1346     1.5251    -4.68%    0.8~1.7
1260&1356     1.6378    +2.36%    0.02~0.6（最干净）
均值 -1.6%   散布 ±3.7pp（≈ 5~6cm，与误差预算 3~6cm 闭合）
```

轨迹体检：161 KF / 1661 位姿 / 8 次重置全恢复 / VIBA2 过。会话内 1260 帧三次
点击像素逐位一致（用户点击极稳，散布不来自重复点击）。

**最终结论：尺度验证通过。** 轨迹米制尺度 ≈ 0 ± 2%（残余即测量分辨率），
无系统性偏差证据；测距功能按「cm 级 / 相对 2~5%」规划。

## 遗留

- **真值 1~2cm 误差未消除**（用户估计物体非精确 1.600）。影响绝对读数带
  ±1.2%，不影响一致性与预算结论。**量准后 `measure --truth <精确值>` 一条命令
  刷新三对读数**，点选结果都留着。该物体将来做「已知参照」校准的标尺，值得量准一次。
- 会话间散布未测（n=1 会话）——用户与一致判定**不必现在做**：测距走向「画面带
  已知参照」当场校准，不依赖会话间稳定性。
- 单对测量噪声 ±3~4pp 是本工具链的分辨率极限（远端视差 11° 决定）；要压低只有
  三条路：拍近一点、基线/转角更大、多对平均。记录在案，不作为待办。
