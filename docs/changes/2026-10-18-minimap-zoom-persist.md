# 2026-10-18 记住小地图的缩放档位

一句话：2D 小窗的 `+` / `−` 档位落盘，下次进 App 还是上次那一档。

## 动机

缩放是**跟着人走的习惯**：有人习惯一屏 14 m（默认），有人习惯凑近看墙角。
每次重开都要重新按几下，而且是同一个动作每天重复。

代码里原来明写着「比例是视图状态，不落盘」（`MainActivity` 的按钮接线那行）——
这条现在作废。

## 改动

- `MapView`：加 `zoomIndex()` / `setZoomIndex(i)`（越界忽略，`-1` = 没存过）。
- `MainActivity`：
  - 新 key `PREF_MAP_ZOOM`（`SharedPreferences`，和三个开关同一份）；
  - `onCreate` 里恢复档位，记下 `zoomSaved`；
  - 两个缩放按钮按完调 `saveZoom()`；长按连按也走同一条。

## 决策

**① 存下标，不存「米 / dp」。**
档位表 `ZOOM_M_PER_DP` 是枚举，**下标才是身份**。存 m/dp 的话每次恢复都要做
「找最近的档」，还要处理表变短的情况；存下标只用夹一下越界。
代价：以后往表中间插一档，旧存档会落到相邻档 —— 可接受，不会崩。

**② 只在档位真的变了才写盘。**
`wireZoomButton` 长按每 95 ms 叫一次，一直按住就是 10 次/秒。`apply()` 虽然异步，
没必要白写。

**③ 全局一份，不按地图分。**
这是**使用习惯**，不是地图属性。换一张图也还是那个缩放。

## 验证

**未验证**（还没编译 / 装机）。要验：

| # | 做什么 | 期望 |
|---|---|---|
| ① | 按几下 `+` → 杀掉 App → 重开 | 小地图还是刚才那一档 |
| ② | 按到最里 / 最外 → 重开 | 停在同一档，再按不越界 |
| ③ | 长按连按到某一档 → 重开 | 落在松手那一档（不是按下那一刻） |
| ④ | 清 App 数据 → 重开 | 默认档（一屏约 14 m） |

## 遗留

- 切片厚度（抽屉里那个滑块）和三个开关早就在同一份 `SharedPreferences` 里，这次没动。
